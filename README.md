# Redux

A collection of code examples and exercises created while learning Redux and centralized state management in JavaScript applications.

## Topics Explored

- **State Management Fundamentals** — understanding application state and centralized state management
- **Redux Store** — creating and accessing the central state store
- **Actions and Action Creators** — describing state changes and creating actions
- **Reducers** — defining how state changes in response to dispatched actions
- **Dispatching Actions** — triggering state updates
- **Immutable State Updates** — updating state without directly modifying existing state
- **Practical Exercises** — experimenting with state updates and Redux data flow


## Getting Started

### Prerequisites

- Node.js and npm
- Basic knowledge of JavaScript
- React fundamentals, for React-based examples

### Clone the Repository

```bash
git clone https://github.com/naba93980/redux.git
cd redux
```

Navigate to the relevant example directory. If it contains a `package.json`, install its dependencies:

```bash
npm install
```

Run the example using the script defined in its `package.json`, or follow the instructions specific to that example.

A hands-on learning repository documenting Redux concepts through code implementations, notes.
